# Intentional Reading Aggregator V1 Specification Package

Status: Draft

This package is the planning index for the V1 redesign of the Intentional Reading aggregator.

The following documents will become the authoritative product and engineering specification:

1. [Product](01-product.md)
2. [Architecture](02-architecture.md)
3. [Content Sources](03-content-sources.md)
4. [Taxonomy and Scoring](04-taxonomy-scoring.md)
5. [Personalization State](05-personalization-state.md)
6. [UI and UX](06-ui-ux.md)
7. [Pipeline and Deployment](07-pipeline-deployment.md)
8. [Security and Dependencies](08-security-dependencies.md)
9. [Testing and Acceptance](09-testing-acceptance.md)

Documents `01` through `09` are the authoritative specification set once approved. Files in `workstreams/` are implementation task packets, not authoritative requirements, and must reference the authoritative specifications rather than duplicate them.

Implementation must not begin until the supervisor marks the necessary specifications as approved.

`design-reference/` will contain the approved Open Design prototype and `DESIGN.md`.

Authoritative content will be supplied later.
