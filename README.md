# News-Agregator

A hobby project to build my own personal news aggregator website powered by RSS.

## About

This is a personal, for-fun project where I pull together news from various sources
using RSS feeds and display them in one place — my own custom news reader.

## Tech Stack

- **Vanilla JavaScript** — no frameworks
- **HTML**
- **CSS**
