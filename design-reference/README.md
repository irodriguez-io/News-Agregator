# Design Reference

`DESIGN.md` is the authoritative visual design reference, and `intentional-reading-prototype.png` is a visual reference.

Prototype example content is illustrative and does not modify the approved source catalog.

The approved product, architecture, security, and contract specifications remain authoritative where applicable.

Each rendered application view has one application masthead/header. There must not be a duplicated `Intentional Reading` masthead or duplicated Settings control. If the prototype PNG appears to repeat them, that repetition is an illustrative stitching/reference artifact rather than a product requirement; the prototype remains authoritative for overall visual intent.
